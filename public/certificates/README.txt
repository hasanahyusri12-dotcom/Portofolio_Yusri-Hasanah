Taruh file gambar/scan sertifikat kamu di folder ini.

Nama file harus cocok dengan yang ada di src/data.js pada array `certificates`,
misalnya:
  react-advanced.jpg
  git-github.jpg
  react-fundamentals.jpg
  web-programming.jpg
  struktur-data.jpg
  logika-c.jpg

Kalau nama sertifikatnya beda, tinggal ubah field "img" di src/data.js
supaya menunjuk ke nama file yang benar. Selama file belum ada, kartunya
otomatis menampilkan ikon sebagai gantinya — jadi aman untuk ditambah
satu per satu.
